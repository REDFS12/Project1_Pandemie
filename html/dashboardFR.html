À propos des Virus

Covid (COVID-19)

Nom complet : Maladie à Coronavirus 2019

Agent causal : SARS-CoV-2 (un coronavirus)

Propagation : Par des gouttelettes dans l'air (toux, éternuements, parole)

Symptômes : Fièvre, toux, fatigue, problèmes respiratoires, perte du goût/odorat

Prévention : Vaccination, lavage des mains, port du masque, aération

Gravité : Peut être légère à sévère, particulièrement dangereux pour les personnes âgées et celles avec des maladies sous-jacentes

Grippe saisonnière

Nom complet : Influenza

Agent causal : Virus de la grippe (généralement type A ou B)

Propagation : Par des gouttelettes de salive (toux, éternuements)

Symptômes : Forte fièvre, frissons, douleurs musculaires, fatigue, toux sèche

Prévention : Vaccin annuel contre la grippe, bonne hygiène

Gravité : Généralement bénigne, mais peut entraîner des complications chez les personnes vulnérables

Paludisme

Agent causal : Parasite Plasmodium, transmis par les piqûres de moustiques (moustique Anopheles)

Propagation : Pas de personne à personne, uniquement par les moustiques

Symptômes : Fièvre, frissons, sueurs, maux de tête, nausées

Prévention : Répulsifs anti-moustiques, moustiquaires, antipaludéens

Gravité : Sans traitement, cela peut être fatal, surtout dans les régions tropicales
